# SPEAR Photonics Digital Twin

Feasibility prototype (v0.1): Bragg grating simulator across C++ TMM core,
pybind11 bindings, FastAPI backend, and React UI with live WebSocket recompute.

## Quick start

```bash
# Python + C++ build (editable install)
uv venv && uv pip install -e .[dev]

# C++ unit tests
cmake -B build -S . && cmake --build build && ctest --test-dir build --output-on-failure

# Python tests (binding + API + WS)
uv run pytest

# Run the stack
uv run uvicorn photonics_twin_app.main:app --reload      # terminal 1
cd src/frontend && npm install && npm run dev            # terminal 2
# open http://localhost:5173
```

## Docker

Two images: backend compiles the C++ core into a wheel and discards the toolchain;
frontend builds the Vite bundle and serves it from nginx, which also proxies the API
and WebSocket so the UI is single-origin.

```powershell
.\scripts\build.ps1              # both images, tagged from pyproject.toml + :latest
.\scripts\build.ps1 -Smoke       # ...then exercise the running stack
docker compose up                # UI + API on http://localhost:5173
```

`build.ps1` takes `-Service backend|frontend`, `-Tag <tag>` and `-NoCache`. Compose
reads `$TAG` (default `latest`), so `$env:TAG='0.1.0'; docker compose up` runs a
pinned build.

The backend reads material data from `$PHOTONICS_DATA_DIR` (set to `/app/data` in the
image). Leave it unset outside containers and it falls back to the repo tree.

## Validation

The reference fixture at `data/validation/quarterwave_si_sio2_reference.json`
is generated by `scripts/compute_reference.py` from the closed-form
expressions in Born & Wolf §1.6.5 — an independent oracle for the simulator's
output. Re-run the script if material coefficients change.

The simulator's stop-band edges agree with the analytical oracle to
within ~1.3 nm; reflectance at the design wavelength matches to 1e-10.
