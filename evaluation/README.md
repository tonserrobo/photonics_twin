# Evaluation - v0.1 Bragg grating prototype

Research outputs for the first vertical slice. The TMM artifacts are generated
by `scripts/evaluate.py` from the installed `photonics_core` C++ kernel; do not
edit them by hand. `outputs/sme_needs_summary.json` is an aggregate extract from
the external SPEAR SME Needs Assessment and is maintained with the assessment,
not regenerated by the simulator script.

## Reproduce

```powershell
uv venv
uv pip install -e .[dev]
.\.venv\Scripts\python.exe scripts\evaluate.py
```

or, with uv managing the environment:

```powershell
uv run python scripts/evaluate.py
```

The script validates the simulator against the independent Born & Wolf
fixtures before writing anything. A tolerance failure aborts the run, so a
broken build cannot silently produce plausible-looking research artifacts.

## Headline results

Reference: Si/SiO2 quarter-wave stack at 1550 nm, 15 periods, vacuum incident
and substrate media.

| Metric | Simulator | Born & Wolf | Absolute error | Budget |
|---|---:|---:|---:|---:|
| Peak reflectance at 1550 nm | 1.000000 | 1.000000 | 1.4e-11 | 1e-3 |
| Low stop-band edge | 1218.85 nm | 1219.34 nm | 0.49 nm | 10 nm |
| High stop-band edge | 2129.01 nm | 2126.73 nm | 2.28 nm | 10 nm |

The 2-period stack has a peak reflectance of 0.888 and a merged high-reflectance
region 1580 nm wide; by 16 periods the peak is 1.0 and the width converges to
907 nm. The C++ kernel measures about 3k wavelength points/ms at 5 periods
(2001 points) on the generation host and stays below 10 ms for the 32-layer cap.

Across the 15-case peak-reflectance matrix (1310/1550/2000 nm x 4-16 periods),
the maximum absolute error against Born & Wolf is `4.96e-13` against a `1e-6`
budget. Stop-band edge validation remains the single 1550 nm, 15-period fixture
because the infinite-stack edge formula is not accurate for small period counts.

The temperature model shifts the 15-period stop-band centre by `3.92 nm` from
20 to 80 C, i.e. `0.065 nm/K`. This uses typical Si/SiO2 thermo-optic and
thermal-expansion coefficients and is linear around 20 C; it is a design aid,
not a calibrated sensor model. Replace the coefficients with measured data
before quoting a sensitivity to an SME.

## Limits

- Normal incidence only; vacuum ambient and substrate.
- Lossless real refractive indices from Sellmeier fits; no absorption, thermal
  drift, apodisation, or fabrication error.
- Benchmark timings are single-host measurements, useful for relative
  comparisons rather than absolute performance claims.
- For low period counts the R >= 0.5 width includes merged sidelobes, so it is
  not the asymptotic photonic band gap. Use the 15-period row for the
  literature comparison.
